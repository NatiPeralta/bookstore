# 📚 Bookstore - Catálogo & Gerenciamento de Livros

Aplicação web desenvolvida como desafio prático do programa de formação **Dev Full Stack Junior** oferecido pela **+praTi**. O projeto simula uma livraria virtual com foco na exibição, organização e manipulação de acervos de livros.

---

## 🚀 Funcionalidades e Destaques

- 📖 **Catálogo Interativo:** Listagem dinâmica de livros disponíveis com informações como título, autor, preço e capa.
- 🔍 **Filtro e Busca:** Recurso para pesquisar títulos e autores com facilidade.
- 📐 **Interface Responsiva:** Design adaptável para navegação em dispositivos móveis e desktops.
- 🛒 **Interatividade:** Estrutura pronta para simulação de carrinho ou salvamento de itens.

---

## 🛠️ Tecnologias Utilizadas

- **[JavaScript (ES6+)](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript):** Lógica da aplicação, manipulação do DOM e dinamismo da interface.
- **[HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML):** Estruturação semântica das telas e formulários.
- **[CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS):** Estilização, componentes modulares e layout responsivo (Flexbox/Grid).
- **[Git & GitHub](https://github.com/):** Controle de versão do código.
